# 自定义装箱率与装盘方式

更新日期：2026-11-17

重新打开 `ui/realtime_dashboard_v3_clean.py` 后，在顶栏「目标」中选择「装箱率」，右侧即可输入百分比，例如 `73.17%`。范围为 `0.01%—100.00%`，支持两位小数。

在百分比右侧选择装盘方式：

- **达标后换下一托盘**：逐箱放置，达到目标后结束当前托盘，剩余箱体继续装下一托盘。整箱不可拆分，最后一箱可能使实际装箱率略高于目标。关闭的托盘不会再参与跨盘补装或救援。
- **单托盘尽量多装**：沿用原有优化与补装流程，目标作为达标判定，达到后仍继续尝试装入箱体。实际装箱量受空间、承重、支撑、平顶和吸盘等现有约束影响。

装箱率口径保持原有体积口径：箱体实际体积之和 ÷ 托盘允许装载空间体积（长×宽×限高）。最后一盘、余量不足或约束受限时可能未达标，结果中仍保留该尾盘及其状态。

Excel、接口运行及本地历史接口 JSON 均通过原来的入口使用本次选择；接口模式仍沿用原来的数据库和接口配置。「指数 192」模式继续保留。

配置示例（比例值为百分比÷100）：

```yaml
success_target:
  mode: fill_rate
  threshold: 0.7317
  loading_mode: stop_at_target  # 或 maximize
```

可在运行日志中核对本次目标与装盘方式。结果 JSON 的 `success_target` 及每盘的 `loading_mode` 也记录所选方式。
